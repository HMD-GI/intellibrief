# 人工回归检查清单

## 1. 天气联想点击后自动查询
1. 启动前后端。
2. 打开“天气情况”页面。
3. 在地区输入框输入“北”。
4. 点击联想候选“北京”。
5. 预期：
   - 输入框自动回填“北京”
   - 不需要再点“仅查询”
   - 页面自动刷新天气、台风和原始 JSON 数据

## 2. 最近查询缓存
1. 在天气页面先后查询“北京”“上海”。
2. 刷新页面或重新进入天气页。
3. 预期：
   - 页面能看到最近查询标签
   - 点击最近查询会直接重新查天气
4. 如需检查 Redis：
   - 读取键 `weather:recent`
   - 预期存在最近查询 JSON 列表

## 3. 飞书机器人卡片发送
1. 在“发送设置”中填写飞书机器人 Webhook。
2. 勾选“简报区块”“天气区块”“台风区块”。
3. 生成一份当天简报。
4. 预期：
   - 飞书群中收到一张消息卡片
   - 卡片头部有地区和日期摘要
   - 中间有全天分时天气
   - 下面有台风信息
   - 最下面有简报标题和查看链接

## 4. 简报与天气分离
1. 生成任意主题简报。
2. 打开简报 HTML。
3. 预期：
   - 简报正文不包含天气、台风模块
   - 天气和台风只在天气页面展示
   - 邮件中为两个区块
   - 飞书中为卡片独立区块
